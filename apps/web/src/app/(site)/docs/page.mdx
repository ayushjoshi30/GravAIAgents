# Documentation

GravAI is the AI agent layer for the Graviton lending platform. It is multi-tenant,
audited end to end, and built for Indian BFSI. Agents are callable three ways:
from Graviton over REST, from any model host over MCP, and from the GravAI console.

These pages describe what exists today. Where something is an interface with a sandbox
adapter rather than a live integration, they say so.

## The ten rules

The platform is built against ten rules. They are not aspirations; each one has tests
behind it.

1. One AI provider in runtime code, behind one adapter layer.
2. Fixed stack — no substitutions.
3. Multi-tenant isolation in the service layer and in the database, proven by tests.
4. No invented numbers: cite the source or return `null` with a reason.
5. PII minimisation; Aadhaar masked to the last 4 digits, never stored in full.
6. Human-in-the-loop for credit decisions, deviations and adverse actions.
7. Document Intelligence: back-off on both paths, shared quota, 10 req/min governor.
8. Audit everything into an append-only, hash-chained log.
9. Tests never spend provider quota.
10. No TODOs in production paths.

> Rule 4 applies to this website too. Every figure quoted on the marketing pages comes
> from `src/lib/platform.ts`, where each one carries its source. The console labels
> anything it could not fetch as example data.
